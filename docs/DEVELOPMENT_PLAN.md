# Development plan

| Phase | Scope and completion check |
| --- | --- |
| 0 | Initialize Git, document the project, verify the scaffold, and commit the foundation. |
| 1 | Build the ten Next.js workspace screens and detail routes with typed sample data and session-only interactions. Verify navigation and key workflows on desktop and mobile. |
| 2 | Add Supabase Auth, field management, and private photo storage. Verify that one user cannot access another user's fields or photos. |
| 3 | Build the wheat Crop Scanner and explain visible symptoms. Verify valid photos, poor-quality inputs, and Gemini failure handling. |
| 4 | Build the Crop Memory Engine. Verify same-field comparisons 15–25 days apart and clear handling of missing or hard-to-compare observations. Use these results for progress reports. |
| 5 | Add forecast-based Weather Guardian cautions. Verify forecast timestamps and unavailable data handling. |
| 6 | Add English and Urdu explanations and inspection reminders. Verify both languages and reminder timing. |
| 7 | Test the full flow, accessibility, and deployment readiness. Deploy when authorized and verify the deployed flow. |

Prioritize a verified scan and same-field comparison before expanding the demo.
